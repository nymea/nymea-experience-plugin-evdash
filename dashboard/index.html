Guides

Using EV Dash

This page explains the main areas of the dashboard and the most common actions.

Getting started

  1. Sign in with your user name and password.
  2. Wait until the status in the header changes to Connected.
  3. Open the Chargers section to see the live status of all available chargers.
  4. Select a charger row to open more details for that charger.

Connection status

  • Connected means live values are up to date.
  • Connecting or Authenticating means the dashboard is restoring access.
  • Disconnected or Connection error means live updates are temporarily unavailable.
  • If needed, sign in again or ask your administrator for support.

Live view

Understand the charger overview

The Chargers section shows the current state of each charger in one place.

  • Name and Car help you identify the charger and the assigned vehicle.
  • Energy manager mode shows whether charging is running in quick, eco or timed operation.
  • Reachable shows whether the charger is currently available.
  • Status shows whether the charger is ready, a car is connected or charging is active.
  • Charging current, phases and current power describe the live charging performance.
  • Session energy shows how much energy has been delivered in the current charging session.

History

Use charging sessions

The Charging sessions section helps you review past charging activity and export it.

  1. Open Charging sessions to load the session history.
  2. Use the car filter if you only want to see sessions for one vehicle.
  3. Set a start date and end date to narrow the time range.
  4. Select Refresh view to update the table.
  5. Select Download CSV to export the currently shown session list.

Everyday tasks

Common things you can do

  • Check whether a vehicle is connected, waiting or actively charging.
  • Compare the live power and charging current of multiple chargers.
  • See how much energy was delivered during the current session.
  • Look up earlier charging sessions for a specific car or time period.
  • Download the visible charging history as a CSV file for further use.
